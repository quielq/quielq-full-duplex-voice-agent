# voice-speak (not built yet)

FastMCP server for TTS control. Tools: `speak`, `append_text`, `pause`, `resume`, `stop`, `duck(gain)`, `unduck`, `interrupt(kind)`, `status`. Notifications: `playback_started`, `played_up_to` (utterance id, word index, ms offset), `playback_finished`. Scheduled after Gate 1. See docs/architecture.md, "Voice servers".
