# Task servers

`clock`, `notes` (SQLite), `thermostat` (mock), `comms` (mock by default, the Mac phone bridge with `comms=bridge`, ADR-024), `lights` (mock, no hardware), and `music` (mock by default, Spotify with `--stages music=spotify`, ADR-022) are built. The bot starts all nine; `--servers` narrows that. `knowledge`, `docs`, and `workspace` are built (ADR-021, ADR-024). See `docs/tools.md` for what each tool does by default and how to add one. `delegate` waits for Thursday's command list, and the real Xiaomi backend waits on the checks in `TODO.md`. Tool names must be unique across servers, and every tool carries all four MCP annotation hints.
